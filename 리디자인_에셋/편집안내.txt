프랑켄슈타인 발표 리디자인 — 편집 안내
==========================================

파일
- 프랑켄슈타인_발표_리디자인.pptx : 최종 발표 파일 (글꼴 포함 저장 → 글꼴이 없는 PC에서도 그대로 보임)
- 리디자인_에셋\ : 슬라이드에 쓰인 이미지 원본 (포토샵 등으로 고친 뒤 PowerPoint에서 교체 가능)
    01 본문(2-6) 배경 / 02 메시지(7) 배경 / 03 표지·마무리 공통 테두리 / 04·05 표지·마무리 배경 장면 / 06 질감 / 07 카드 사진
- 리디자인_에셋\시안_비교.pdf : 페이지마다 디자인 시안(위)과 새로 만든 슬라이드(아래)를 나란히 놓은 검토용 PDF

슬라이드 구성 (레이아웃 3개)
- '표지' 레이아웃 → 1쪽, 8쪽
  찢어진 종이 테두리, FRANKENSTEIN, '명저읽기 토론 발표', 4조 배지, 발표자/조원 줄, 큰 제목 자리가 레이아웃에 있습니다.
  각 슬라이드에는 배경 장면(슬라이드 배경 그림)과 큰 제목만 들어 있고, 8쪽에는 '함께 생각해 볼 질문' 상자가 더 있습니다.
- '본문' 레이아웃 → 2~6쪽
  종이 질감 배경, 왼쪽 찢어진 가장자리, 오른쪽 위 성 일러스트, FRANKENSTEIN, 바닥글(4조 | 프랑켄슈타인 전권), 쪽 번호,
  제목·부제 자리가 모두 레이아웃에 있어서 다섯 장이 항상 똑같습니다.
- '메시지' 레이아웃 → 7쪽 : 본문과 똑같은 틀을 어두운 배경에 얹은 것(우리 조 메시지 강조용 색 대비).

카드 양식 (2~7쪽 공통)
- 사진 → 색 태그(+선) → 명조 제목 → 본문 → 아래쪽 회색 인용 박스
- 태그 색 순서: 1번 진홍 / 2번 녹색 / 3번 회녹색. 인용 박스의 왼쪽 막대와 라벨도 같은 색입니다.
  (예외: 4쪽은 의미에 맞춰 축복 = 녹색, 재앙 = 진홍)
- 사진 높이는 카드 글 양에 맞춰 슬라이드마다 조금 다릅니다(카드 안이 비어 보이지 않도록). 나머지 구조·글꼴·간격은 같습니다.
- 카드 하나가 그룹으로 묶여 있습니다(통째로 이동 가능). 안쪽 글은 한 번 더 클릭하면 선택됩니다.

자주 하는 편집
- 글자 수정 : 글상자를 클릭해 바로 수정.
- 카드 사진 교체 : 사진 오른쪽 클릭 → 그림 바꾸기 (둥근 모서리·자르기 비율 유지).
- 표지/마무리 배경 장면 교체 : 슬라이드 빈 곳 오른쪽 클릭 → 배경 서식 → 그림 또는 질감 채우기 → 삽입.
- 배경·성 일러스트·찢어진 가장자리·바닥글·4조 배지·발표자 줄 수정 : 보기 → 슬라이드 마스터 → 해당 레이아웃에서
  한 번만 고치면 그 레이아웃을 쓰는 모든 슬라이드에 반영됩니다.
- '우리 조의 답' 패널 : PowerPoint '액자' 도형에 짙은 녹색 질감 그림을 채운 것(노란 조절점으로 모서리 크기 조절).

사용 글꼴 (파일에 포함 저장됨)
- HY견명조 : 슬라이드 제목, 카드 제목, 표지 큰 제목
- KoPubWorld바탕체 Bold/Medium : 부제, 패널 글, 바닥글, 발표자/조원, 질문
- Noto Sans KR (Regular/Medium/Bold) : 본문, 태그, 인용 박스
- Garamond : FRANKENSTEIN, 섹션 번호, 쪽 번호  /  Times New Roman : VS

슬라이드 노트
- 원본 PPT의 발표 대본(참고 쪽수 포함)을 모든 슬라이드 노트에 그대로 옮겼습니다.
- 디자인 시안과 원본 문구가 다른 곳은 대본 아래 '— 수정 기록 —'에 원래 문구와 수정 이유를 적어 두었습니다(2, 3, 6, 7쪽).

노트 페이지
- 보기 → 슬라이드 노트, 또는 인쇄 → '슬라이드 노트'로 슬라이드 그림 + 발표 대본을 함께 인쇄할 수 있습니다.
